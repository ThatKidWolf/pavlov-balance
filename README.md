# Pavlov Shack balance table

The balancing table for Wolf's Pavlov Shack server: Pavlov's own (vankruptgames/BalancingTable, Beta_5.1) plus rows
for custom weapons by their item name. The server loads it with `BalanceTableURL=ThatKidWolf/pavlov-balance/main`.

Columns: Cost, KillBonus, BaseDamage, ArmourDamage, ArmourPenetration, HelmetDamage, HelmetBleed, Weight,
FalloffModifier, MinFalloffDist, MaxFalloffDist.
